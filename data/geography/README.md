# Географічний набір даних

Ця директорія містить шаблон CSV для власного географічного корпусу. Репозиторій навмисно не постачає неперевірений перелік географічних назв або координат.

- `geographic-names-template.csv` — заголовок з рекомендованими полями.
- `../..` — методика запуску та контракт вихідних колонок у [docs/geographic-dictionary.md](../../docs/geographic-dictionary.md).

Для кожного рядка бажано зберігати стабільний `id`, тайську назву, тип об'єкта, адміністративний рівень, координати, назву джерела, URL, точну ліцензію та ідентифікатор запису в джерелі. Не залишайте ліцензію порожньою у публічному датасеті й не вгадуйте її.

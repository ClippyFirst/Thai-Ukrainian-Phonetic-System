ФОНЕТИКО-ГРАФЕМНИЙ АНАЛІЗАТОР · v0.6.1

Тайське написання → українське передавання

Введіть тайський текст, слово або явно поділені склади. Сервіс токенізує текст, відокремлює пунктуацію, латиницю й цифри, а для відомих слів виконує лексичну сегментацію складів.

01 / ВХІД

Тайський текст

Вставте цілий текст або статтю. Після аналізу сервіс покаже один суцільний український кандидат і окремий IPA-вихід; деталі по сегментах можна розгорнути нижче. Ctrl/⌘ + Enter — проаналізувати.

Строгий режим утримується від непідтвердженої вимови. М’який шукає структурно можливі склади, але залишає невирішені фрагменти позначеними. Суперм’який формує український кандидат для кожного тайського фрагмента через приблизну IPA → українська адаптацію; повне покриття не гарантує правильної вимови.

Приклади:

02 / IPA → УКРАЇНСЬКА

Маєте транскрипцію IPA?

Вставте IPA з дужками або скісними рисками. Адаптер розпізнає поширені позначення тону, наголосу, довготи, нерелізованого вибуху й африкат із tie bar. Невідомий сегмент блокує результат, а не вгадується. Придих у /kʰ pʰ tʰ tɕʰ/ позначається апострофом після приголосного (к' п' т' ч'); самостійний /h/ → «г». Тон, довгота й наголос показуються як нейтралізовані ознаки, а не губляться непомітно.

МЕТОД

IPA є проміжним контрольним представленням і обов’язковою межею адаптера. Український кандидат формується з типізованого фонетичного результату через IPA; тайська орфографія не передається до адаптера IPA → українська.

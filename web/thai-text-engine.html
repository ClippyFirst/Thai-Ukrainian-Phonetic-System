ДОДАТКОВИЙ ІНСТРУМЕНТ CLIPPYFIRST

Рушій транскрипції тайського тексту

У проєкті є окремий пакетний Python-рушій для обробки тайського тексту. Він може додавати до рядків CSV латинську романізацію RTGS, IPA та попередній український запис, побудований через IPA. Це додатковий інструмент для тих, кому потрібна пакетна транскрипція слів і фраз; він не перекладає значення тексту.

ТРИ ПОДАННЯ — ДВА НЕЗАЛЕЖНІ МАРШРУТИ

Що саме обчислює рушій

  1. RTGS: окрема латинська романізація через PyThaiNLP 5.4.0 (newmm + royin) із закріпленим CC0 словником.
  2. IPA: аналіз тайського написання на фонемний IPA та, коли підтримано, окремий широкий поверхневий IPA.
  3. Українська адаптація: форма створюється лише з типізованого IPA через наявний IPA → Ukrainian адаптер ClippyFirst.

RTGS не є джерелом української форми. Якщо IPA-аналіз неповний або не підтриманий, IPA та український результат утримуються, а не вгадуються. Технічно повний результат не означає, що власну назву вже перевірив фахівець.

ПАКЕТНА ОБРОБКА

Як скористатися

Це пакетний Python CSV-інструмент у репозиторії (початково оформлений як збирач географічного словника), а не окреме поле введення на цій вебсторінці. Додайте тайський текст у колонку name_th (або задайте іншу назву через --thai-column). Підійдуть звичайні слова, фрази чи більші текстові фрагменти; для кожного рядка інструмент формує окремий результат.

python -m pip install -e ".[geography]"
python scripts/build_geographic_dictionary.py input.csv \
  --thai-column name_th \
  --output build/transcription.csv

Скрипт зберігає початкові колонки й додає RTGS, фонемний IPA, широкий поверхневий IPA, український результат, статус, метод сегментації та попередження. RTGS — окрема латинська романізація; українська форма будується тільки через IPA.

СТАН ДОКАЗІВ

Дослідницький інструмент із попередніми результатами

Результати не є експертно підтвердженою транскрипцією. Технічний smoke test підтверджує роботу програмного маршруту, але не точність вимови кожного слова чи фрази. Для відповідального використання важливі результати слід перевіряти за надійними джерелами або з фахівцем тайської мови.

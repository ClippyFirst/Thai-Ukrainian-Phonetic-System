ДОДАТКОВИЙ ІНСТРУМЕНТ CLIPPYFIRST

Рушій для тайських географічних назв

У проєкті є окремий пакетний рушій, який збагачує CSV із тайськими географічними назвами романізацією RTGS, IPA та попереднім українським записом, побудованим через IPA. Він призначений для підготовки географічного словника, а не для перекладу назв.

ТРИ РЕЗУЛЬТАТИ — ДВА НЕЗАЛЕЖНІ МАРШРУТИ

Що саме обчислює рушій

  1. RTGS: окрема латинська романізація через PyThaiNLP 5.4.0 (newmm + royin) із закріпленим CC0 словником.
  2. IPA: аналіз тайського написання на фонемний IPA та, коли підтримано, окремий широкий поверхневий IPA.
  3. Українська адаптація: форма створюється лише з типізованого IPA через наявний IPA → Ukrainian адаптер ClippyFirst.

RTGS не є джерелом української форми. Якщо IPA-аналіз неповний або не підтриманий, IPA та український результат утримуються, а не вгадуються. Технічно повний результат не означає, що власну назву вже перевірив фахівець.

ПАКЕТНА ОБРОБКА

Як скористатися

Це Python CSV-інструмент у репозиторії, а не окреме поле введення на цій вебсторінці. Підготуйте CSV із колонкою name_th та, за можливості, джерельними метаданими (source_url, source_license, ідентифікатор запису, координати).

python -m pip install -e ".[geography]"
python scripts/build_geographic_dictionary.py data/geography/input.csv \
  --thai-column name_th \
  --output build/geographic-dictionary.csv

Скрипт зберігає початкові колонки й додає RTGS, фонемний IPA, широкий поверхневий IPA, український результат, статус, метод сегментації та попередження.

СТАН ДОКАЗІВ

Дослідницький інструмент, не готовий географічний довідник

Реальний корпус географічних назв ще не включено: джерела, ліцензії, координати та українські екзоніми мають бути перевірені окремо. Технічний smoke test підтверджує роботу програмного маршруту, але не правильність вимови власних назв. Для публікації набору потрібні незалежна перевірка тайської вимови/IPA та окрема редакторська перевірка українських форм.

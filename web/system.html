ЯК ЦЕ ПРАЦЮЄ

Як сервіс читає тайський текст

Сервіс спершу запускає нативний JavaScript-порт FastThaiG2P у браузері, отримує IPA для слів із перевіреного локального словника, а потім пропонує її попередній практичний запис українськими літерами. Якщо трапляється слово поза словником, браузер спершу використовує нативний JavaScript-порт TLTK OOV; Pyodide завантажується лише як резерв сумісності, якщо нативний шлях не може повернути повний результат. Це не переклад: значення слова не змінюється.

ОДИН РУШІЙ

FastThaiG2P → IPA → український кандидат

FastThaiG2P — єдиний рушій, який визначає тайську вимову на сайті. Браузер спершу запускає ClippyFirst-maintained JavaScript-порт: нормалізацію, PyThaiNLP newmm і пошук у 13 144 Wiktionary-позначених IPA-записах. Для таких словникових збігів Python/Pyodide не завантажується. Якщо локальний словник не покриває хоча б один токен, інтерфейс запускає нативний TLTK OOV-аналізатор у браузерному Worker. Pyodide залишається останнім резервним шляхом сумісності, а не основним OOV-механізмом. Якщо і він не повертає повний IPA, сервіс показує помилку, а не підміняє результат здогадкою.

IPA — проміжний запис звуків. Сервіс зберігає сирий результат FastThaiG2P, зокрема межі складів, тонові позначки та довготу голосних. Оскільки зовнішній IPA ще не підтверджено незалежними фахівцями як фонемний або широкий поверхневий, його не позначають жодним із цих статусів.

Український запис — попередня практична адаптація отриманої IPA за наявними правилами проєкту. Це кандидат для читання, а не гарантовано правильна вимова чи офіційний стандарт.

УКРАЇНСЬКА АДАПТАЦІЯ IPA

Як передаємо початковий звук /j/

Якщо /j/ стоїть на початку складу перед голосною, український запис використовує відповідну йотовану літеру. Це контекстне правило IPA → українська, а не механічна заміна тайської літери.

IPA на початку складуУкраїнський запис
/ja/я
/je/, /jɛ/є
/ji/ї
/jo/, /jɔ/йо
/ju/ю

Важливо розрізняти «е» та «є»: /e/ або /ɛ/ без початкового /j/ передаємо як е; /je/ або /jɛ/ на початку складу — як є. Кодовий /j/ залишається й: наприклад, /aj/ → «ай». Для /jɯ/ та /jɤ/ окремого йотованого правила немає: це «йи» та «йе».

Адаптер застосовує це перетворення лише на початку IPA-послідовності або після явної межі складу (крапки чи пробілу). Якщо межу не позначено, система не повинна вгадувати її.

ЩО ВИ БАЧИТЕ

Три частини результату

  • Українськими літерами — головний попередній практичний кандидат.
  • IPA FastThaiG2P — сирий запис вимови, який дозволяє перевірити джерело української адаптації.
  • Подробиці складів — IPA кожного складу, тон, довгота, застосовані правила та походження результату.

Тони й довгота показуються в IPA та метаданих, але не повністю відтворюються українськими літерами. Через це два записи не можуть бути тотожними.

01

Введення тексту

Текст передається з інтерфейсу до локального Web Worker у цьому браузері. Він не надсилається на API або зовнішній сервер.

02

FastThaiG2P

Нативний JavaScript Worker перевіряє SHA-256 локальних ресурсів і виконує словникову частину без Python-модулів. Для OOV він ліниво завантажує локальний TLTK-пакет даних і виконує портований парсер у браузері; Pyodide Worker створюється лише як fail-closed резерв сумісності.

03

IPA → українська

IPA проходить через окремий адаптер. Невідомі символи не вгадуються; для підтримуваних фрагментів український результат позначається як попередній.

04

Обмеження

Якщо IPA неповна або містить непідтримувані звуки, сервіс повідомляє про це й утримується від непідтвердженого результату.

ПОЗНАЧКИ

Що означають повідомлення

Попередній український кандидат

IPA адаптовано за правилами проєкту, але незалежної експертної перевірки ще немає.

IPA отримано

FastThaiG2P повернув повний IPA для всіх фрагментів, які вдалося обробити.

Не вдалося визначити повний IPA

Є непідтриманий фрагмент або сторонній текст. Сервіс не використовує інший рушій як резерв.

Непідтримуваний IPA-символ

Для такого символу немає правила української адаптації; відповідний кандидат утримується.

Технічні подробиці для дослідників

Проміжний IPA-контракт

Український запис не створюється прямою заміною тайських літер. IPA — це окремий проміжний рівень, і саме вона є входом до українського адаптера.

FastThaiG2P повертає зовнішню IPA, яка в поточному дослідженні ще не класифікована як фонемна або широка поверхнева. Тому вона зберігається окремо від обох цих полів. Адаптація може сформувати лише попередній кандидат; непідтримані сегменти залишаються невизначеними.

RTGS — окрема латинська система запису тайської мови. Вона не використовується на сайті як альтернативний рушій або fallback.

Придихові /kʰ pʰ tʰ tɕʰ/ у практичному українському записі позначаються апострофом після приголосного (к' п' т' ч'); окремий звук /h/ передається як «г» без апострофа.

Рушій закріплено на upstream commit 4e82a291b4cf2876326744c6580121e9986ad354. Пакет включає окремі словникові й fallback-дані. Власник репозиторію дозволив їх публікацію в межах дослідницького бета-проєкту; це не скасовує умов сторонніх ліцензій. Для шести TLTK fallback-файлів у пакеті 1.9.1 джерела послідовно вказують BSD-3-Clause: README повідомляє про зміну ліцензії пакета з версії 1.2.2, setup.py декларує BSD-3-Clause і включає ці файли, MANIFEST.in включає LICENSE.txt, а сам LICENSE.txt містить BSD-3-Clause умови. Кореневий LGPL-3.0 LICENSE збережено як окремий репозиторний notice; PKG-INFO з GPLv3 описує застарілу версію 1.1.7. Для fallback-компонентів застосовуємо BSD-3-Clause та зберігаємо всі її умови й атрибуцію. Це джерельно обґрунтована оцінка, не юридичний висновок.

САЙТ

Розгортання

GitHub Pages залишається єдиним хостингом. Публічний інтерфейс спершу використовує нативний JavaScript Worker; після словникового промаху запускає браузерний TLTK OOV-парсер, а same-origin Pyodide Worker — лише якщо нативний шлях не повертає повного результату. FastAPI не є частиною публічного шляху. Це гібридний перехідний режим, а не повна заміна Python: Нативний TLTK OOV-порт пройшов 64/64 точних перевірок типізованого сервісного JSON у модульному та Worker-тестах; Pyodide збережено як fail-closed резерв. Фактичні cold/warm/offline/mobile performance-бюджети й ручна перевірка доступності на assistive technology ще не виміряні.

ОБМЕЖЕННЯ

Чого сервіс поки не гарантує

  • Не гарантує правильну вимову кожного слова або речення.
  • Не замінює тайський словник, викладача чи носія мови.
  • Не перекладає текст і не визначає його значення.
  • Не є офіційним стандартом українського запису тайської мови.
  • Українська адаптація зовнішньої IPA поки не пройшла незалежну експертну перевірку.

Автоматичні тести показують, що програма працює за заданими правилами. Але вони не доводять, що кожне слово звучить правильно. Для цього потрібна окрема перевірка фахівцями.

ЯК ЦЕ ПРАЦЮЄ

Як сервіс читає тайський текст

Сервіс запускає закріплений FastThaiG2P у браузері через Pyodide, отримує IPA, а потім пропонує її попередній практичний запис українськими літерами. Це не переклад: значення слова не змінюється.

ОДИН РУШІЙ

FastThaiG2P → IPA → український кандидат

FastThaiG2P — єдиний рушій, який визначає тайську вимову на сайті. Браузер запускає той самий Python-рушій FastThaiG2P у Web Worker через Pyodide. Старий JavaScript/RTGS-дослідницький код не використовується як альтернативний рушій. Якщо FastThaiG2P не повертає повний IPA, сервіс показує помилку, а не підміняє результат іншим методом.

IPA — проміжний запис звуків. Сервіс зберігає сирий результат FastThaiG2P, зокрема межі складів, тонові позначки та довготу голосних. Оскільки зовнішній IPA ще не підтверджено незалежними фахівцями як фонемний або широкий поверхневий, його не позначають жодним із цих статусів.

Український запис — попередня практична адаптація отриманої IPA за наявними правилами проєкту. Це кандидат для читання, а не гарантовано правильна вимова чи офіційний стандарт.

ЩО ВИ БАЧИТЕ

Три частини результату

  • Українськими літерами — головний попередній практичний кандидат.
  • IPA FastThaiG2P — сирий запис вимови, який дозволяє перевірити джерело української адаптації.
  • Подробиці складів — IPA кожного складу, тон, довгота, застосовані правила та походження результату.

Тони й довгота показуються в IPA та метаданих, але не повністю відтворюються українськими літерами. Через це два записи не можуть бути тотожними.

01

Введення тексту

Текст передається з інтерфейсу до локального Web Worker у цьому браузері. Він не надсилається на API або зовнішній сервер.

02

FastThaiG2P

Pyodide запускає закріплену Python-версію FastThaiG2P із локально завантаженими wheel-пакетами, словником і fallback-даними. Інший G2P-рушій не підключається.

03

IPA → українська

IPA проходить через окремий адаптер. Невідомі символи не вгадуються; для підтримуваних фрагментів український результат позначається як попередній.

04

Обмеження

Якщо IPA неповна або містить непідтримувані звуки, сервіс повідомляє про це й утримується від непідтвердженого результату.

Технічні подробиці для дослідників

Проміжний IPA-контракт

Український запис не створюється прямою заміною тайських літер. IPA — це окремий проміжний рівень, і саме вона є входом до українського адаптера.

FastThaiG2P повертає зовнішню IPA, яка в поточному дослідженні ще не класифікована як фонемна або широка поверхнева. Тому вона зберігається окремо від обох цих полів. Адаптація може сформувати лише попередній кандидат; непідтримані сегменти залишаються невизначеними.

RTGS — окрема латинська система запису тайської мови. Вона не використовується на сайті як альтернативний рушій або fallback.

Придихові /kʰ pʰ tʰ tɕʰ/ у практичному українському записі позначаються апострофом після приголосного (к' п' т' ч'); окремий звук /h/ передається як «г» без апострофа.

Рушій закріплено на upstream commit 4e82a291b4cf2876326744c6580121e9986ad354. Пакет включає окремі словникові й fallback-дані. Власник репозиторію дозволив їх публікацію в межах дослідницького бета-проєкту; це не скасовує умов сторонніх ліцензій. Для TLTK-derived fallback точна сфера BSD-3-Clause та LGPL-3.0 на рівні окремих файлів залишається неоднозначною, тому обидва повідомлення збережені в публічних правових повідомленнях.

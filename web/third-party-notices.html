Словникові дані FastThaiG2P

Браузерний build залишає лише IPA-записи з per-entry позначкою джерела Wiktionary. Модельно згенеровані, вручну додані та записи без підтвердженого джерела не включаються. Список слів скорочено до ключів цих IPA-записів. OOV fallback FastThaiG2P залишається окремим компонентом.

Атрибуція: автори Wiktionary; Kaikki.org / Wiktextract. Дані походять із тайського розділу Wiktionary через Kaikki.org і поширюються на умовах CC BY-SA 4.0. Цей набір змінено: записи без per-entry позначки Wiktionary вилучено, модельно згенеровані та manual-записи не включаються, словник токенізатора скорочено до збережених IPA-ключів.

  • Kaikki.org — Thai Wiktionary data та ліцензія
  • Wiktionary — Copyrights
  • CC BY-SA 4.0 — офіційний текст ліцензії
  • FastThaiG2P — закріплений вихідний код

Прозорий набір даних та його машинозчитуваний manifest мають бути доступні разом із runtime wheel після проходження publication gate.

FastThaiG2P

Програмний код FastThaiG2P поширюється під Apache License 2.0. У вихідному репозиторії також є NOTICE від Amazon.

  • Apache License 2.0 — FastThaiG2P
  • NOTICE — FastThaiG2P

TLTK-derived fallback

FastThaiG2P вказує, що його OOV fallback походить із Thai Language Toolkit (TLTK). Вендорений файл коду містить заголовок TLTK version 1.3.8 і BSD-3-Clause notice. П'ять із шести перевірених fallback-файлів мають ідентичні Git blob SHA з файлами в репозиторії TLTK; pickle-файл збережений у розпакованому вигляді.

Публічна сторінка PyPI для TLTK 1.3.8 вказує BSD-3-Clause. Репозиторій TLTK водночас містить окремий кореневий LGPL-3.0 LICENSE; цей файл також збережено у каталозі повідомлень як історичний evidence. Точне співвідношення root LICENSE до релізу 1.3.8 ще підлягає остаточній перевірці, тому публічний bundle залишається gated.

  • BSD-3-Clause — TLTK
  • LGPL-3.0 — файл LICENSE у репозиторії TLTK
  • PyPI — TLTK 1.3.8
  • Репозиторій TLTK

Статус публікації

Публічне розповсюдження Pyodide runtime і Python wheels наразі вимкнене до завершення перевірки атрибуції, походження даних і комплекту ліцензійних повідомлень. CI використовує лише тимчасові тестові bundle; це не означає, що ці файли вже опубліковані на GitHub Pages.

Наявність ліцензії на програмний код не є автоматичним дозволом на розповсюдження будь-яких вбудованих словників або корпусів.

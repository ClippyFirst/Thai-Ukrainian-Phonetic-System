Правові повідомлення та джерела даних

Ліцензії програмних компонентів і походження словникових даних, що використовуються в опублікованій браузерній бета-версії сервісу.

Словникові дані FastThaiG2P

Браузерний build залишає лише IPA-записи з per-entry позначкою джерела Wiktionary. Модельно згенеровані, вручну додані та записи без підтвердженого джерела не включаються. Список слів скорочено до ключів цих IPA-записів. OOV fallback FastThaiG2P залишається окремим компонентом.

Атрибуція: автори Wiktionary; Kaikki.org / Wiktextract. Дані походять із тайського розділу Wiktionary через Kaikki.org і вихідні матеріали Wiktionary зазначені як dual-licensed під CC BY-SA 4.0 та GFDL 1.3; цей набір даних поширюється в цьому bundle під CC BY-SA 4.0. Цей набір змінено: записи без per-entry позначки Wiktionary вилучено, модельно згенеровані та manual-записи не включаються, словник токенізатора скорочено до збережених IPA-ключів.

  • Kaikki.org — Thai Wiktionary data та ліцензія
  • Wiktionary — Copyrights
  • CC BY-SA 4.0 — ліцензія цього набору
  • GNU Free Documentation License 1.3 — альтернативна ліцензія вихідного матеріалу Wiktionary
  • Завантажити відфільтрований набір IPA та словник токенізатора (ZIP)
  • FastThaiG2P — закріплений вихідний код

Відфільтрований набір IPA і словник токенізатора опубліковані як окремий ZIP вище. Його походження, фільтрація та атрибуція описані в цьому розділі; ZIP і runtime bundle входять до перевірки цілісності GitHub Pages deployment.

TLTK-derived fallback

FastThaiG2P вказує, що його OOV fallback походить із Thai Language Toolkit (TLTK). Вендорений файл коду містить заголовок TLTK version 1.3.8 і BSD-3-Clause notice. П’ять із шести перевірених fallback-файлів мають ідентичні Git blob SHA з файлами у зафіксованому знімку репозиторію TLTK; шостий файл `sylform_var.pkl` точно дорівнює результату `bz2.decompress()` для `tltk/sylform_var.pklz`. Усі шість зіставлень і перетворення відтворюються перевірочним скриптом у репозиторії.

Заголовок вендореного parser-файла посилається на TLTK 1.3.8 та BSD-3-Clause. Окремо перевірений знімок TLTK за commit `0cef4bcfbdd675f589783dd4134b87b9bb9fbb93` містить `setup.py` version 1.9.1 із BSD-3-Clause, кореневий `LICENSE` LGPL-3.0, `LICENSE.txt` із BSD-подібними умовами та застарілий `PKG-INFO` 1.1.7/GPLv3. Це не доводить, що кожен скопійований файл підпадає під однакову ліцензію. Обидва повідомлення — BSD і LGPL — збережено в опублікованому bundle; точна сфера їх застосування до кожного файла залишається неоднозначною та потребує остаточного правового уточнення. Власник дозволив публікацію дослідницької бета-версії, але це не є відмовою від умов сторонніх ліцензій.

Статус публікації

Pyodide 0.29.5, закріплені Python wheels, потрібні runtime-файли та фільтрований набір даних опубліковані в GitHub Pages bundle після окремого дозволу власника репозиторію від 2026-11-05. Публікація здійснюється для дослідницької бета-версії. Вона не змінює ліцензійних умов FastThaiG2P, Pyodide, PyThaiNLP, Wiktionary чи TLTK. Для TLTK-derived fallback збережено обидва повідомлення BSD-3-Clause і LGPL-3.0; точна сфера їх застосування до кожного файла залишається відкритим питанням.

Наявність ліцензії на програмний код не є автоматичним дозволом на розповсюдження будь-яких вбудованих словників або корпусів.

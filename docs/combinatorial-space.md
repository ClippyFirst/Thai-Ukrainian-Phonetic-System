# Combinatorial space

The system distinguishes several nested but non-equivalent spaces.

1. Graphemically possible: combinations permitted by the chosen data schema.
2. Orthographically valid: combinations licensed by Thai spelling conventions.
3. Phonotactically possible: combinations compatible with Thai syllable structure.
4. Phonologically possible: combinations surviving phonological interpretation.
5. Lexically attested: combinations appearing as lexical forms.
6. Corpus-attested: combinations observed in a defined corpus.

The script generate_syllable_space.py computes only a structural upper bound from the declared inventory. It must not be described as the number of Thai syllables.

This distinction prevents a common research error: multiplying inventory sizes and treating the result as a linguistic inventory.

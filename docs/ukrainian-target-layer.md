# Ukrainian target layer

The Ukrainian target is external: ClippyFirst/Ukrainian-Phonetic-Inventory.

The intended correspondence pipeline is:

Thai surface IPA
→ feature vector
→ Ukrainian candidate generation
→ phonetic distance
→ Ukrainian phonotactic constraints
→ Ukrainian orthographic constraints
→ ranked target candidates.

A candidate is a model preference, not an assertion of identity. Thai lexical tone is retained as a separate suprasegmental layer.

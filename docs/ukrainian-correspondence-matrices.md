# Повні матриці тайсько-українських відповідностей: IPA та RTGS

**Статус:** методична специфікація PARTIAL; окремий runtime-маршрут RTGS → українська реалізовано. Таблиці фіксують проєктні відповідності й покриття реєстрів, але не є незалежно ад'юдикованим фонетичним gold та не встановлюють офіційного українського стандарту.

## 1. Дві методики — два незалежні ланцюжки

**A. Фонетична методика (IPA-first):** тайське написання → структурна/лексична сегментація → фонологія тайської → фонемний і поверхневий IPA → українська адаптація з IPA. Українська форма обчислюється лише з типізованого PhoneticResult.

**B. Романізаційна методика (RTGS-first):** тайське написання → наявний RTGS-модуль → латинський запис RTGS → українське графемне відтворення RTGS. Українська форма отримується з латинського рядка RTGS, а не з IPA. Це навмисно окремий маршрут.

У RTGS-режимі kh/ph/th передаються як кх/пх/тх, окреме h — як х. У фонетичному режимі /kʰ pʰ tʰ/ мають проєктні форми к'/п'/т', а /h/ — г. Це різні методики, не суперечність.

RTGS не є ISO 11940:1998. RTGS — вимовно-орієнтована система запису латиницею; ISO 11940:1998 — окрема орфографічна транслітерація.

## 6. RTGS-склади та рими → українська передача

Український результат утворюється не механічним прочитанням латинських назв букв. Спочатку розпізнаються приголосні диграфи, позиційні голосні рими та спеціальні послідовності йотованого y. Такий підхід наслідує структуру тайсько-російських практичних таблиць, але форми адаптовано до української графіки й українських голосних.

| RTGS-послідовність | Українська передача | Застосування |
|---|---|---|
| kh | кх | Початковий придиховий велярний диграф |
| ph | пх | Початковий придиховий губний диграф |
| th | тх | Початковий придиховий зубний диграф |
| ch | ч | Африката; RTGS не розрізняє її придиховість |
| ng | нг | Велярна носова |
| h | х | Самостійний RTGS сегмент |
| ya | я | y як початок складу перед a |
| ye | є | y як початок складу перед e |
| yi | ї | y як початок складу перед i |
| yo | йо | y як початок складу перед o |
| yu | ю | y як початок складу перед u |
| ae | е | Рима /ɛ/; не розкладати на а+е |
| ue | и | Рима /ɯ/; українське наближення |
| oe | е | Рима /ɤ/; українське наближення |
| ia | іа | Рима /ia/ |
| uea | иа | Рима /ɯa/ |
| ua | уа | Рима /ua/ |
| ai | ай | Рима /aj/ |
| ao | ау | Рима /aw/ |
| am | ам | Рима /am/ |
| io | іу | Рима /iw/ у поточному порту |
| ui | уй | Рима /uj/ |
| eo | еу | Рима /ew/ |
| aeo | еу | Рима /ɛw/ |
| oei | ей | Рима /ɤj/ |
| oi | ой | Рима /ɔj/ або /oj/ за реєстром |
| iao | іо | Складна рима, яку поточний RTGS-порт подає як iao |
| uai | уай | Складна рима з кінцевим /j/ |
| ueai | иай | Складна рима з /ɯ/ та кінцевим /j/ |

Однолітерні відповідники, коли не входять до спеціальної рими/диграфа: a → а, e → е, i → і, o → о, u → у; b → б, d → д, f → ф, k → к, l → л, m → м, n → н, p → п, r → р, s → с, t → т, w → в, y → й.

## 8. Джерела, версії та обмеження

1. **Реалізація RTGS:** PyThaiNLP 5.4.0, pythainlp/transliterate/royin.py, commit 7f26adf5ce09c3d77c39ca2ef86f7138e9071088. У репозиторії збережені Apache-2.0 attribution та ліцензійний текст.
2. **BGN/PCGN 2002 Agreement:** [офіційний урядовий PDF](https://assets.publishing.service.gov.uk/media/5ab4e60aed915d78b9a459f5/ROMANIZATION_OF_THAI.pdf). Пояснює позиційні відповідники приголосних, відсутність позначення тону/довготи та потребу перевіряти власні назви за словником. Це споріднений референс, не твердження про повну тотожність усіх деталей порту PyThaiNLP.
3. **Royal Institute:** [Romanization, Transliteration, and Transcription for the Globalization of the Thai Language](https://www.orst.go.th/FILEROOM/CABROYINWEB/DRAWER004/GENERAL/DATA0000/00000639.FLP/html/105/) — інституційний матеріал про призначення й обмеження романізації.
4. **Порівняльний російський підхід:** [Тайско-русская практическая транскрипция](https://ru.wikipedia.org/wiki/Тайско-русская_практическая_транскрипция). Використовується як порівняльний приклад позиційних таблиць і передачі RTGS диграфів, не як норматив для української.
5. **ISO:** [ISO 11940:1998](https://www.iso.org/standard/20574.html) — окрема орфографічна транслітерація; [ISO 11940-2:2007](https://www.iso.org/standard/29544.html) — спрощена транскрипційна система, що не розрізняє короткість/довготу.
6. **IPA-first:** чинні src/thai_ukrainian/ukrainian_adaptation.py і src/thai_ukrainian/phonetic_result.py.

## 9. Статус доказів

- **DONE_VERIFIED — інвентарне покриття:** відображені 44 приголосні графеми та 41 римовий запис; onset/coda розділені.
- **DONE_VERIFIED — реалізація RTGS UI adapter:** окремий браузерний маршрут RTGS → українські графеми не викликає IPA-адаптер; невідомий RTGS-символ спричиняє відмову від результату.
- **PARTIAL — мовна правильність:** таблиці є прозорою специфікацією проєктних відповідностей; вони не підтверджують усі лексичні читання, сегментацію, тон, поверхневу фонетику чи українську норму.
- **BLOCKED — незалежна валідація:** потрібні незалежна тайська експертна перевірка IPA/сегментації та окрема ад'юдикація українських форм. Це зовнішні дослідницькі залежності, а не внутрішній технічний борг.

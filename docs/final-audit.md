# Final audit

## Current release

Version 0.3.0 research foundation + validation harness.

### Implemented

- 44 Thai consonant graphemes with class and positional IPA data.
- Core vowel inventory plus context-dependent/glide records.
- Tone marks separated from phonological tones.
- Five-tone engine with live/dead classification.
- Thai graphemic decomposition.
- Explicit and conservative implicit-vowel detection.
- Onset/coda distinction with regression coverage for clusters and vowel glides.
- Broad phonemic/surface IPA pipeline.
- Feature-distance Ukrainian candidate ranking using a reproducible target snapshot.
- Evidence and claim registries.
- Structural combinatorial-space accounting.
- Corpus record schema and deterministic JSONL evaluation harness.
- Negative tests and GitHub Actions CI.

### Not claimed complete

- Full Thai lexical segmentation.
- Exhaustive special orthography.
- Complete ห นำ, รร, silent-letter and morphology-dependent grammar.
- Connected-speech narrow phonetics.
- Corpus-derived accuracy or lexical coverage.
- Empirically calibrated Ukrainian candidate probabilities.
- One universally correct Ukrainian orthographic rendering.

## Quantitative audit

Authoritative counts are generated by scripts/generate_derived.py and scripts/generate_syllable_space.py.

Structural syllable-space numbers are upper bounds over declared records. They are not counts of valid Thai syllables, lexical forms or corpus-attested forms.

## Reproducibility

A release is reproducible when a clean environment installs the package, regenerates derived JSON, and passes the complete test suite.

## Empirical validation gate

The project must not publish an accuracy percentage until a named, versioned/licensed gold dataset has actually been processed. The evaluation harness records explicit denominators and excludes missing gold fields from each metric.

# Final audit

## Current release

Version 0.2.0 research foundation.

### Implemented

- 44 Thai consonant graphemes with class and positional IPA data.
- Core vowel inventory plus context-dependent ai/am records.
- Tone marks separated from phonological tones.
- Five-tone engine with live/dead classification.
- Thai graphemic decomposition.
- Explicit and conservative implicit-vowel detection.
- Onset/coda distinction that avoids treating a true onset cluster as a coda.
- Broad phonemic/surface IPA pipeline.
- Feature-distance Ukrainian candidate ranking using a reproducible target snapshot.
- Evidence registry and claim registry.
- Combinatorial-space accounting that explicitly avoids equating structural combinations with lexical inventory.
- Corpus-validation protocol and schemas.
- Negative tests and CI.

### Not claimed complete

- Full Thai lexical segmentation.
- Exhaustive special orthography.
- Complete ห นำ, รร, silent-letter and morphology-dependent grammar.
- Connected-speech narrow phonetics.
- Gold-corpus accuracy numbers.
- Empirically calibrated candidate probabilities.
- One universally correct Ukrainian orthographic rendering.

## Quantitative audit

The authoritative counts are generated by scripts/generate_derived.py and scripts/generate_syllable_space.py. The committed JSON reports are derived artifacts and should be regenerated in CI.

No lexical or corpus coverage percentage is reported until a licensed corpus is actually processed.

## Reproducibility criterion

A release is considered reproducible only when a clean environment can install the package, regenerate derived JSON, and pass the complete test suite.

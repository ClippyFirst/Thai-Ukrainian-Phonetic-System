# Тайсько-українська практична транскрипція

**Thai → Ukrainian Practical Transcription** — проєктна система передавання сучасної стандартної тайської мови українською графікою. Вона призначена для читабельного запису особових і географічних назв, назв установ, культурних об'єктів та іншої лексики.

Це опис системи ClippyFirst у репозиторії [Thai-Ukrainian-Phonetic-System](https://github.com/ClippyFirst/Thai-Ukrainian-Phonetic-System), а не переклад тайсько-російської таблиці. Російська практична транскрипція є порівняльним орієнтиром структури викладу; українські відповідники визначаються власними правилами та українським цільовим інвентарем.

**Статус:** проєктна практична система, а не затверджений український національний стандарт. Програмна реалізація й тести існують, але незалежна перевірка повного набору тайських IPA-форм та українських написань ще не завершена. Результати для власних назв і лексичних винятків залишаються попередніми.

## Основний принцип

Система передає не тайські літери самі по собі, а вимову, визначену після структурного та фонологічного аналізу:

**Тайське написання → складова структура → тайська фонологія → IPA → українська фонетична адаптація → практичний український запис.**

Одна тайська графема може мати різні українські відповідники залежно від позиції в складі. Різні тайські літери можуть зливатися в один результат, якщо в кінці складу вони позначають той самий звук. Це відрізняє транскрипцію від побуквеної транслітерації.

## Приголосні

Таблиці відображають поточний реєстр тайських приголосних та реалізований IPA → Ukrainian адаптер. IPA є проміжним джерелом українського результату.

### На початку складу

| Тайські літери | IPA | Український запис |
|---|---:|---|
| ก | /k/ | к |
| ข ฃ ค ฅ ฆ | /kʰ/ | к' |
| ง | /ŋ/ | нг |
| จ | /tɕ/ | ч |
| ฉ ช ฌ | /tɕʰ/ | ч' |
| ซ ศ ษ ส | /s/ | с |
| ญ ย | /j/ | я/є/ї/йо/ю перед відповідною голосною на початку складу; інакше й |
| ฎ ด | /d/ | д |
| ฏ ต | /t/ | т |
| ฐ ฑ ฒ ถ ท ธ | /tʰ/ | т' |
| ณ น | /n/ | н |
| บ | /b/ | б |
| ป | /p/ | п |
| ผ พ ภ | /pʰ/ | п' |
| ฝ ฟ | /f/ | ф |
| ม | /m/ | м |
| ร | /r/ | р |
| ล ฬ | /l/ | л |
| ว | /w/ | в |
| ห ฮ | /h/ | г |
| อ | /ʔ/ або носій голосної | ∅ |

Апостроф у формах **к', п', т', ч'** — проєктне позначення придиху, а не твердження про усталену українську норму. /h/ → «г» є практичною апроксимацією, а не фонетичною тотожністю. Графема อ не отримує автоматичного українського приголосного відповідника.

### Наприкінці складу

У тайській мові кінцеві приголосні нейтралізуються до обмеженого набору фінальних звуків. Українська форма визначається кінцевою вимовою, а не початковим значенням тайської літери.

| Тайські літери в кінці складу | Кінцевий IPA | Український запис |
|---|---:|---|
| ป บ พ ฟ ภ | /p/ | п |
| จ ช ซ ฌ ฎ ฏ ด ต ฐ ฑ ฒ ถ ท ธ ศ ษ ส | /t/ | т |
| ก ข ฃ ค ฅ ฆ | /k/ | к |
| ง | /ŋ/ | нг |
| ณ น ญ ร ล ฬ | /n/ | н |
| ม | /m/ | м |
| ย | /j/ | й |
| ว | /w/ | в; у кінці складу може вимовлятися як нескладове [u̯] |

Наприклад, ด передає /d/ на початку складу, але /t/ у кінці; บ — /b/ на початку, але /p/ у кінці; ร — /r/ на початку, але /n/ у кінці.

## Голосні

Короткість і довгота зберігаються в аналітичному результаті, але за замовчуванням не позначаються подвоєнням українських букв.

| Тайська фонема | Український відповідник |
|---|---|
| /i, iː/ | і |
| /e, eː/ | е |
| /ɛ, ɛː/ | е |
| /ɯ, ɯː/ | и |
| /ɤ, ɤː/ | е |
| /a, aː/ | а |
| /u, uː/ | у |
| /o, oː/ | о |
| /ɔ, ɔː/ | о |

/ɯ/ → «и» та /ɤ/ → «е» — практичні наближення, а не твердження про фонетичну тотожність.

### Початковий /j/ перед голосною: українські йотовані літери

Коли IPA засвідчує /j/ саме на початку складу безпосередньо перед голосною, українська адаптація передає цю послідовність однією йотованою літерою або нормативною послідовністю **йо**:

| IPA на початку складу | Український запис | Правило |
|---|---|---|
| /ja/ | я | UA-JA |
| /je/, /jɛ/ | є | UA-JE |
| /ji/ | ї | UA-JI |
| /jo/, /jɔ/ | йо | UA-JO |
| /ju/ | ю | UA-JU |

**Не плутати /e, ɛ/ з /je, jɛ/:** без початкового /j/ обидві голосні передаються як **е**; за наявності складопочаткового /j/ — як **є**. Отже, /e/ → **е**, але /je/ → **є**. Для /ɯ/ та /ɤ/ окреме правило йотованої голосної тут не встановлено: /jɯ/ і /jɤ/ залишаються послідовностями **йи** та **йе**.

Це позиційне правило не є глобальною заміною кожного /j/. У коді та інших не-початкових позиціях /j/ зберігає відповідник **й**: /aj/ → **ай**, /ɔːj/ → **ой**. Правило застосовується лише за наявності явної межі складу (початок IPA-послідовності, крапка або пробіл); якщо межу не встановлено, адаптер не повинен здогадуватися про новий склад.

### Дифтонги та послідовності з глайдами

| IPA | Український запис |
|---|---|
| /ia/ | іа |
| /ɯa/ | иа |
| /ua/ | уа |
| /aj/, /aːj/ | ай |
| /am/ | ам |
| /aw/, /aːw/ | ав |
| /iw/ | ів |
| /uj/ | уй |
| /ew/, /eːw/, /ɛːw/ | ев |
| /ɤːj/ | ей |
| /ɔːj/, /oːj/ | ой |
| /iaw/ | іав |
| /uaj/ | уай |
| /ɯaj/ | иай |

Рими обробляються як цілісні фонологічні послідовності. Тайський глайд /w/ передається українською літерою **в** і на початку складу, і в кінці рими: /wa/ → **ва**, /daːw/ → **дав**, /kʰaːw/ → **к'ав**, /mɛːw/ → **мев**. У фінальній позиції українське «в» може реалізуватися як нескладове [u̯] — подібно до білоруського [ў], але без запровадження окремої літери. Тому ми не записуємо /Vw/ через голосну «у».

Деякі складні рими мають контекстно або лексично залежний статус; наявність відповідника в таблиці не означає, що кожне можливе написання вже розпізнається безпомилково.

## Особливості тайського письма

- **อ.** На початку складу може бути носієм голосної або позначати гортанну зімкненість; в інших структурах бере участь у написанні голосної. Його не можна всюди передавати однією українською літерою.
- **Голосні перед приголосним.** เ-, แ-, โ-, ไ- та ใ- аналізуються з урахуванням фонологічного місця, а не читаються в порядку появи знаків.
- **ห นำ.** Написане ห може впливати на тоновий клас, не стаючи вимовленим початковим приголосним.
- **Лексичні й історичні написання.** รร, ฤ/ฤๅ, ฦ/ฦๅ, ์, ทร, อ นำ та деякі хибні збіги приголосних потребують контексту або словникового підтвердження.
- **Межі слів.** Пробіли в тайському тексті не завжди збігаються з межами слів. Помилка сегментації може змінити склад, тон і кінцевий приголосний.

## Тони та довгота

Тайська має п'ять лексичних тонів. Система обчислює та зберігає тон в аналітичному результаті, але не передає його обов'язковими діакритиками у звичайному українському практичному записі. Довгота залишається доступною в IPA й структурних даних, але зазвичай не позначається подвоєнням української голосної. Український рядок є практичним записом, а не повною фонетичною транскрипцією.

## Як це реалізовано в репозиторії

1. **Тайські дані:** data/thai/consonants.csv описує 44 приголосні графеми, класи й позиційні значення; data/thai/vowels.csv містить 41 запис рим і голосних конструкцій.
2. **Фонологічний аналіз:** Python-рушій розбирає структуру складу, голосні, початкові й кінцеві приголосні, живі/мертві склади, тон, ห นำ та спеціальні орфографічні випадки.
3. **Типізований IPA:** PhoneticResult зберігає фонемний і консервативний поверхневий IPA, межі, довготу, тон, походження та невизначеність. IPA є справжньою межею між тайським аналізом і українським адаптером.
4. **Українська адаптація:** web/src/ipa-ua.js реалізує відповідності IPA → українська графіка; /w/ послідовно передається літерою «в» у всіх позиціях.
5. **Браузерний сервіс:** сайт використовує FastThaiG2P у браузерному Worker-контурі. Його зовнішній IPA не оголошується автоматично незалежно підтвердженим фонемним чи поверхневим шаром; український рядок із нього позначається як попередній.
6. **Перевірки:** Python- і браузерні тести перевіряють правила, відмову від непідтримуваних IPA-символів, походження й узгодженість реалізацій. Програмна відповідність не замінює експертної лінгвістичної оцінки.

## Відмінності від тайсько-російської практичної транскрипції

Російська система є прикладом структури позиційних таблиць, але український аналог не можна отримати простою заміною російських літер українськими.

| Питання | Тайсько-російська таблиця (порівняльно) | Система ClippyFirst |
|---|---|---|
| /ɯ/ | «ы» або контекстні рішення | «и» як українське наближення |
| Придихові /kʰ pʰ tʰ/ | «кх, пх, тх» | «к', п', т'» у проєктній нотації |
| /h/ | «х» | «г» як практична апроксимація |
| /ŋ/ | «нг» | «нг» |
| /w/ у будь-якій позиції | Залежить від конкретної таблиці | «в»; у коді можливе нескладове [u̯] |
| Тон і довгота | Не відтворюються повністю в практичному рядку | Зберігаються окремо в IPA й аналітичних даних |

Російська таблиця не є проміжним кроком генерації українського результату. Українські відповідники мають власні правила, код і статус доказовості.

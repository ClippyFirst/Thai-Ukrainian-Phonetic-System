# Thai consonants

The machine-readable inventory distinguishes consonant grapheme, onset value, coda value, consonant class and positional restriction.

Multiple graphemes collapse to the same phoneme. In coda position, Standard Thai neutralizes many onset distinctions into a small final set. This is a core reason that a character-to-character transliterator is linguistically inadequate.

The adopted core final set is p, t, k, ʔ, m, n, ŋ, j and w. Academic descriptions also note unreleased final p/t/k.
